# ศูนย์ร้องเรียนการฉ้อโกงออนไลน์ - ACSC Thailand

เว็บไซต์สำหรับรับแจ้งร้องเรียนการฉ้อโกง หลอกลวง และการละเมิดออนไลน์

## 🌐 ฟีเจอร์หลัก

### หน้าบ้าน (Frontend) - สำหรับผู้เสียหาย
- **หน้าแรก (index.html)** - แสดงข้อมูลและการต้อนรับผู้เยี่ยมชม
  - Hero section ที่สวยงาม
  - ข้อมูลบริการ
  - ขั้นตอนการแจ้งร้องเรียน
  
- **แจ้งร้องเรียน (report.html)** - ฟอร์มสำหรับผู้เสียหาย
  - ข้อมูลส่วนตัว
  - รายละเอียดการฉ้อโกง
  - อัปโหลดหลักฐาน
  - ข้อมูลเพิ่มเ��ิม
  - ยินยอมเงื่อนไข
  
- **ตรวจสอบสถานะ (check-status.html)** - ติดตามสถานะคำร้องเรียน
  - ค้นหาด้วยเลขที่คำร้องเรียนและอีเมล
  - แสดงสถานะการจัดการแบบเรียลไทม์
  - Timeline ของการดำเนินการ
  - FAQ ส่วนผู้ใช้

### หลังบ้าน (Backend/Admin Dashboard) - สำหรับผู้ดูแล
- **Admin Dashboard (admin.html)** - ระบบจัดการสำหรับผู้ดูแล

   - เลือกช่วงวันที่

   - สรุปตามสถานะ
   - พิมพ์รายงาน

## 📋 ประเภทการฉ้อโกง

1. **Phishing** - ดักจับข้อมูล
2. **Romance Scam** - หลอกลวงทางใจ
3. **Job Scam** - ลวงงานปลอม
4. **Payment Scam** - ลวงการชำระเงิน
5. **Investment Scam** - ลวงการลงทุน
6. **Fake Account** - บัญชีปลอม
7. **Malware** - ซอฟต์แวร์ร้าย
8. **อื่นๆ** - ประเภทอื่น

## 🔄 สถานะคำร้องเรียน

- **รอการตรวจสอบ** (Pending) - เพิ่งส่งมา/รอตรวจสอบเบื้องต้น
- **กำลังสอบสวน** (Investigating) - อยู่ระหว่างการสอบสวน
- **เสร็จสิ้น** (Completed) - สอบสวนและบันทึกเสร็จสิ้นแล้ว

## 🚀 วิธีใช้งาน

### สำหรับผู้เสียหาย

1. **เข้าไปที่หน้า "แจ้งร้องเรียน"**
   - เยี่ยมชม `report.html`

2. **กรอกข้อมูล**
   - ชื่อ-นามสกุล, อีเมล, โทรศัพท์, ที่อยู่
   - ประเภทการฉ้อโกง, วันที่, แพลตฟอร์ม
   - รายละเอียดการฉ้อโกง
   - ข้อมูลผู้ต้องสงสัย

3. **อัปโหลดหลักฐาน**
   - สกรีนช็อต
   - เอกสาร
   - บันทึกการสนทนา

4. **ยินยอมเงื่อนไข**
   - ยืนยันการเก็บรักษาข้อมูล
   - เลือกติดตามการรับแจ้ง

5. **ส่งแบบฟอร์ม**
   - บันทึกเลขที่คำร้องเรียน
   - ตรวจสอบสถานะผ่าน check-status.html

### ตรวจสอบสถานะ

1. **เข้าไปที่หน้า "ตรวจสอบสถานะ"**
   - เยี่ยมชม `check-status.html`

2. **กรอกข้อมูล**
   - เลขที่คำร้องเรียน
   - อีเมลที่ใช้ลงทะเบียน

3. **ดูผลลัพธ์**
   - สถานะการจัดการ
   - Timeline ของการดำเนินการ
   - หมายเหตุจากทีม

### สำหรับ Admin

1. **เข้าไปที่หน้า "Admin"**
   - เยี่ยมชม `admin.html`

2. **ล็อกอิน**
   - Username: `admin`
   - Password: `admin123`

3. **ดู Dashboard**
   - สถิติโดยรวม
   - จำนวนคำร้องเรียน

4. **จัดการคำร้องเรียน**
   - ไปที่แท็บ "รายการคำร้องเรียน"
   - ค้นหาและกรองคำร้องเรียน

## 💾 การเก็บข้อมูล

ระบบใช้ **Local Storage** ของ Browser เพื่อเก็บข้อมูลทั้งหมด:
- ข้อมูลจะยังคงอยู่เมื่อปิด Browser
- เมื่อล้าง Cache อาจจะหายไป
- สำหรับการใช้งานจริง ต้องเชื่อมต่อกับฐานข้อมูล
